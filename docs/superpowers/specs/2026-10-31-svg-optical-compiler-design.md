# Precision Optical Compiler SVG Suite Design Spec (2026-10-31)

## 1. Visual World & Craft Floor Contract (`/impeccable` + `/make-prompt-better`)
- **World**: Precision Optical Compiler (Linear / Stripe / Teenage Engineering inspired).
- **Surface Palette**:
  - Matte Carbon Stage: `#08090D` -> `#0C0E14`
  - Optical Glass Plane: `#121520` with `1px` specular border `#23283B`
  - Primary Alabaster Ink: `#F5F3EC`
  - Muted Steel Secondary Ink (tinted from surface hue, never pure gray): `#949AB1`
  - Fluff / Redaction Signal: `#FF5A36` (Warm Optical Coral)
  - Verified Certificate Signal: `#00E58B` (Optical Emerald)
- **Hard Craft-Floor Bans Enforced**:
  - Zero eyebrow kickers (`FIG. 01 //`, `01 //`) above headings.
  - Zero card-inside-card nesting and zero `4px` colored `border-left` stripes.
  - Zero decorative bobbing (`translateY` loops on static cards).
  - Monospace used strictly for code, `[P1]`/`[T1]`/`[V1]` tokens, CLI commands, and benchmark numerals.
  - Includes `@media (prefers-reduced-motion: reduce)` fallback in every SVG.
