# Adoption experiment proposal

After the installer and one host journey have been verified, invite a small consented pilot through a channel the maintainer chooses. No invitations, posts, telemetry, or external messages have been sent by this change.

Ask three participants to install in a disposable project, improve a complete prompt containing a deadline and output order, compare the rewrite with the original, and restore the previous installation. Record whether each person finds the entry point, time to a useful result, lost requirements, recovery failures, and whether they choose to return later. Report missing follow-up and the small sample size. Three successful journeys are a proposed early learning threshold, not an adoption forecast.

Fix any data loss, misleading lint interpretation, or lost requirement before promoting a shareable example. A future social card should use factual current copy, link to source instructions, and have a text alternative. Do not infer virality from stars or impressions alone.
